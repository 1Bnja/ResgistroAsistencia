# Cumplimiento Normativo

## Ley N° 19.628 - Protección de Datos Personales
- **Cumplimiento**:
    - Los datos de asistencia se almacenan de forma segura.
    - Solo personal autorizado tiene acceso.
    - Se garantiza la confidencialidad de los datos biométricos (si aplica).

## Ley N° 21.459 - Marco sobre Ciberseguridad
- **Cumplimiento**:
    - Se implementan medidas de seguridad robustas (HTTPS, Hardening).
    - Se cuenta con un plan de respuesta a incidentes.
    - Se reportan vulnerabilidades críticas si afectan a terceros.

## Normas de Gobierno Digital
- **Cumplimiento**:
    - Uso de estándares abiertos.
    - Interoperabilidad y seguridad por diseño.
    - Protección de la identidad digital.
